# HTTP Server

In my journey to understand more about the fundamental concepts of computer science, this time I'm going to build an http server in C from scratch. By doing this I see myself learning about networking engineering, tcp/ip fundamentals, http protocols and network communication in general. 

This is an on-going project, and I'm mainly following the documentation and tutorial from Beej Jorgensen ([here](https://beej.us/guide/bgnet/html/split/index.html)), and other textbooks and documentations not worth mentioning here to keep it simple.
